# 提示词反推 500–800 字设计

## 目标

将爆款拆解中的“提示词反推”目标输出从原来的 150–300 字提升到 500–800 字。每次任务只调用模型一次；分镜拆解、计费、前端和其他生成能力保持不变。

## 生成流程

1. 首次请求明确要求直接输出一条完整的 500–800 字中文提示词，并保留主体、场景、镜头、光线色调、节奏情绪五层结构。
2. 模型只调用一次，不做字数补偿重试。
3. 清理代码围栏、首尾引号及多余换行后直接返回。
4. 移除当前静默截断到 600 字的行为；即使模型偶尔少于 500 字或超过 800 字，也返回完整结果，不做程序拼接、截断或失败退款。

## 修改范围

- A 组：`server/content_domains/breakdown.py`
- 关联测试：`tests/test_breakdown.py`
- 设计和实施计划文档

## 测试

- 初始提示语包含 500–800 字要求且不再包含 150–300 字。
- 提示词反推每个任务只调用模型一次。
- 601–800 字及超过 800 字的返回结果均不再被静默截断。
- 继续清理代码围栏、首尾引号与多余换行。
- 运行爆款拆解及内容域相关回归测试。
