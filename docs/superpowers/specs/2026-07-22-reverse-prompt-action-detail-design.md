# 提示词反推动作细节设计

## 目标

将爆款视频“提示词反推”的输出要求从现有五层结构升级为六层结构，新增独立的“动作与时序”层，使反推结果可以直接描述人物动作、镜头运动以及动作发生的先后顺序。输出仍是一条完整的 500–800 字中文提示词，每个任务仍只调用模型一次。

## 输出结构

反推提示词要求覆盖以下六层：

1. 主体：人物或产品的外观、身份、服装和状态。
2. 场景：环境、关键道具、前中后景及空间关系。
3. 动作与时序：按“起始—发展—结束”的顺序描述人物表情、视线、手势、肢体姿态、走位及人物与道具的互动；同时说明对应的镜头跟随、推进、拉远、摇移或转场时机。
4. 镜头：景别、视角、构图和整体运镜风格。
5. 光线与色调：照明方向、氛围、材质和色彩质感。
6. 节奏与情绪钩子：画面节奏、情绪变化和吸引观众继续观看的重点。

动作描述必须是可执行的连续过程，避免只使用“自然地动起来”“展示产品”等笼统表述。关键帧无法证明的动作不应被描述为原视频事实；模型可以基于可见信息补充适合原创生成的合理动作，但应保持人物、场景和内容逻辑一致。

## 实现范围

- 修改 `server/content_domains/breakdown.py` 中 `_reverse_prompt_from_frames` 的模型指令。
- 更新 `tests/test_breakdown.py` 中的提示词结构测试，锁定六层结构、人物动作、镜头动作和起始—发展—结束时序要求。
- 保留 500–800 字目标、纯提示词输出格式、当前模型路由、20 点计费、失败退款和单次模型调用逻辑。
- 不修改前端、接口字段、数据库或视频生成接口。

## 错误处理与兼容性

模型偶尔输出少于 500 字或超过 800 字时，继续返回完整结果，不截断、不拼接、不补偿重试。现有清洗逻辑与空结果错误保持不变。调用方无需适配新字段，因为响应仍是原有字符串提示词。

## 验收标准

- 模型指令明确使用六层结构。
- 动作层同时要求人物动作和镜头运动。
- 动作按起始、发展、结束描述先后关系。
- 输出仍要求 500–800 字且只输出一条提示词。
- 每个反推任务仍只调用模型一次。
- 相关单元测试和现有爆款拆解测试全部通过。
