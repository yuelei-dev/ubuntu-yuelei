**Goal:** 将提示词反推改为单次请求目标输出 500–800 字，并停止静默截断返回内容。

**Tech Stack:** Python 3.10、`unittest`、OpenAI 兼容多模态调用。

## Global Constraints

- 提示语目标为 500–800 字。
- 不做字数重试、程序拼接、截断或因字数偏离而退款。
- 只修改 A 组源码、关联测试及规格/计划文档。
