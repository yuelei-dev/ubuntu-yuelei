# 爆款拆解固定 20 点实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将分镜拆解与提示词反推统一为每个链接固定 20 点，并通过两个单组 PR 同步后端计费和前端展示。

**Architecture:** 后端继续由 `points.cost_of` 统一预扣，并由 `breakdown_batch_refund` 按失败链接结算退款；前端只展示与后端一致的价格，不自行计算或扣点。为遵守组锁，A 组后端和 C 组前端分别创建 PR。

**Tech Stack:** Python 3.10、`unittest`、原生 HTML/JavaScript、GitHub Actions。

## Global Constraints

- 分镜拆解和提示词反推均按每个有效链接 20 点计费。
- 批量分镜拆解最多 5 条，按有效链接数量乘以 20。
- 每个失败链接退 20 点；全部失败时退款不超过实际预扣金额。
- 一个 PR 只修改一个组及关联测试；不直接推送或合并 `main`。
- 两个 PR 默认创建为草稿，后端 PR 先于前端 PR 合并。
- 不写入或提交服务器密码、API Key 等敏感信息。
