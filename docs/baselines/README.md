# 服务器行为基线

这个目录保存服务器运行代码与 Git `main` 发生漂移时的可追溯导入记录。

基线记录只证明“服务器当时实际运行了什么”，不证明实现正确。已知 Bug 必须在后续独立分支和 PR 中修复，不能在同步过程中顺手改写。

## 当前基线

`test-production-behavior-20260729.json` 记录了 2026-07-29 从生产服务器只读取样、脱敏后同步到测试服务器的行为基线：

- 生产服务器本地仓库提交：`473421bfd6d762cfcf0b114319939c35cfd8a3ef`

- 运行文件与生产服务器本地仓库提交并不完全一致，因此清单逐文件记录 SHA-256。
- 本次导入只覆盖清单中的源码和静态资源，不删除仓库中已有的测试、文档或开发文件。

明确排除环境文件、数据库、用户数据、上传/生成内容、缓存、日志、备份、密钥、密码、Token、私钥、生产域名、Nginx 配置、TLS 证书、生产专属环境变量和 `stats.json`。
