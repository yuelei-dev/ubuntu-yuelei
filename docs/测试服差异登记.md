## 三、部署登记

- 命名约定（沿用既有惯例）：`/opt/huangque-deployments/pr<号>-<sha>-<时间戳>` 与 `/opt/huangque-deploy-backups/` 同名备份
- 每次部署走 `ship --exact-files`（精确文件模式；content_domains 一律精确模式，禁止整目录 `--delete`），完成后执行：`drift_sentinel.py --verify-deploy <文件>` 通过后 `--bless-deploy <文件>`（记录写入 `/home/ubuntu/hq-drift/deploy_bless.jsonl`）
- PR 预览目录：统一 `pr<号>-<sha8>` 命名；只保留进行中的 PR，合并/关闭即清理
- 部署记录必须包含：commit SHA、文件清单、服务、操作者、关联 PR/任务号
